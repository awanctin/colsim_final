# data

Encounter banks, CSV, one row per encounter (own vessel, targets, duty gate, stratum).
Read with `colsim.evaluation.bank.load`.

| File | Use |
|---|---|
| `far_bank/cat_q_w567.csv` | Evaluation bank, far-start rows, window 567 steps |
| `train_alarm.csv` | Training bank of the Hybrid policy, episodes start at the alarm |
